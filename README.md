# W2 — protótipo de entretenimento

Site estático responsivo com três minijogos e pontuação fictícia salva no navegador.

## Como publicar pelo GitHub
1. Entre em https://github.com/anaclaudialitz6-gif/W2
2. Toque em **Add file** → **Upload files**.
3. Envie os quatro arquivos desta pasta: `index.html`, `styles.css`, `app.js` e `README.md`.
4. Toque em **Commit changes**.
5. Abra **Settings** → **Pages**.
6. Em **Build and deployment**, escolha **Deploy from a branch**.
7. Selecione a branch `main` e a pasta `/ (root)`, depois **Save**.
8. Aguarde a publicação. O endereço aparecerá na própria tela do GitHub Pages.

## Como editar
- Textos e seções: `index.html`
- Cores, fontes, tamanhos e aparência: `styles.css` (procure `:root`)
- Perguntas e regras dos jogos: `app.js` (procure `const questions`, `memoryGame` e `reactionGame`)
- Para alterar pelo celular: abra o arquivo no GitHub, toque no lápis (Edit), faça a alteração e use **Commit changes**.

## Importante
Esta versão é somente entretenimento. Os pontos são fictícios, locais ao navegador e não têm valor financeiro. Não há cadastro real, pagamentos, depósitos, saques, apostas ou prêmios.
